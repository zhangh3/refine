1. 项目简介

refine 是 NASA 兰利研究中心开源的二维/三维非结构网格自适应平台 （C 语言实现，Apache-2.0 协议）。其主要面向线性与高阶曲面单纯形 （三角形、四面体）网格的度量驱动 (metric-driven) 各向异性自适应； 同时也提供有限的混合单元（四边形、棱柱、金字塔、六面体）存储、修改 与就地分裂能力，可用于附面层网格的处理与转换。

典型工作流：

  1. 从 .egads CAD 模型自举 (bootstrap) 出第一套体网格；
  2. 由解 (scalar) 重构 Hessian，构造 multiscale 各向异性度量；
  3. 按度量场对网格执行自适应（split / collapse / swap / smooth）；
  4. 把解从旧网格插值到新网格继续 CFD 迭代；
  5. 循环 (loop)，直到解与网格互相一致。

命令行可执行 ref（串行）/ refmpi（并行 EGADSlite） / refmpifull（并行 + 完整 EGADS+OpenCASCADE）。 所有算法亦以 library 形式暴露，可被 C/C++/Fortran 程序链接调用。

版本说明：本手册基于源码树 src/ 与 src/ref_subcommand.c、src/ref_subdiv.c、 src/ref_metric.c、src/ref_recon.c、 src/ref_adapt.c 等文件直接生成，所引用行号均来自当前仓库。

6.2.2 算法时间线

每个 pass 在 ref_adapt_pass（ref_adapt.c:620）中以下列顺序执行操作： swap → collapse → swap → collapse(放大 ratio) → (swap, smooth)×N → swap → split → swap → (smooth, swap)×N → collapse(放大 ratio) → swap → (smooth, swap)×N → 可选 unlock_tet。 顺序的设计目的：先“清理”拓扑（互换/塌缩去除短小或低质边），再做加密 （split），最后再次互换+光顺以提升网格质量。

7. 度量场 (Riemannian Metric Field)

在 refine 中，所有“目标网格大小/形状”信息以对称正定 3×3 矩阵 场 $\mathcal{M}(\mathbf{x})\in\mathbb{R}^{3\times3}_{\text{SPD}}$ 表示，每节点存 6 个独立分量 $(M_{xx},M_{xy},M_{xz},M_{yy},M_{yz},M_{zz})$。其几何意义： $\mathbf{v}^\top\mathcal{M}\mathbf{v}=\|\mathbf{v}\|_\mathcal{M}^2$ 为度量长度平方。理想网格使每条边的度量长度 $\ell_\mathcal{M}\approx 1$，且每单元相对于 $\mathcal{M}$ 接近单位正三角形/四面体。

7.1 基本量

  • 边度量长度 $\ell_\mathcal{M}(P_0,P_1)=\int_0^1 \sqrt{\mathbf{e}^\top \mathcal{M}(P_0+s\mathbf{e})\,\mathbf{e}}\,ds$， $\mathbf{e}=P_1-P_0$；refine 提供多种数值积分（--ratio-method）。 最快近似为 $\ell\approx\sqrt{\mathbf{e}^\top\mathcal{M}_{\!\text{avg}}\mathbf{e}}$。
  • 单元度量体积 $V_\mathcal{M}=\sqrt{\det\mathcal{M}}\,V_{\text{Euclidean}}$。
  • “本征间距” $h_i=1/\sqrt{\lambda_i}$，其中 $\lambda_i$ 为 $\mathcal{M}$ 特征值， 对应特征向量给出主方向。

7.2 复杂度 (Complexity)

定义为 $$\mathcal{C}(\mathcal{M})=\int_\Omega\sqrt{\det\mathcal{M}(\mathbf{x})}\,d\mathbf{x}$$ 与最终顶点数近似呈正比关系（continuous mesh 框架，Loseille & Alauzet）。 ref_metric_complexity（ref_metric.c:1888）通过 sub-tet 分解：每个高阶单元被切成若干子四面体，节点贡献为 $\sum_{k\in\text{node}}\sqrt{\det\mathcal{M}_k}\,V_{\text{tet}}/4$ （三角形为 $/3$）。MPI 并行下做 allsum 归约。

7.3 复杂度归一化

ref_metric_set_complexity 把当前 $\mathcal{M}$ 缩放到目标 $\mathcal{C}^*$：在 n-D 中 $$\mathcal{M}\leftarrow \alpha\,\mathcal{M},\qquad \alpha=\Bigl(\frac{\mathcal{C}^*}{\mathcal{C}}\Bigr)^{2/n}.$$

8. 多尺度度量数学（Multiscale Metric）

多尺度度量用于控制 $L^p$ 范数下的解插值误差。给定标量场 $u(\mathbf{x})$ 和重构 Hessian $H(u)\in\mathbb{R}^{3\times3}_{\text{sym}}$， 定义“绝对值 Hessian”

$$|H| = R\,\mathrm{diag}(|\lambda_i|)\,R^\top,\qquad H=R\Lambda R^\top.$$

对目标 $L^p$ 误差最小，存在最优各向异性度量 (Loseille & Alauzet 2011)：

$$\boxed{\; \mathcal{M}_p(\mathbf{x})=\;D_p\;\bigl(\det|H|\bigr)^{-\frac{1}{2p+n}}\,|H|\,,\qquad D_p = \mathcal{C}^{2/n}\!\!\left(\int_\Omega(\det|H|)^{\frac{p}{2p+n}}\right)^{\!\!-2/n}\;}$$

其中 $n=2,3$ 为空间维度。$D_p$ 由全局复杂度 $\mathcal{C}$ 规范化获得。

8.1 实现步骤

  1. ref_recon_hessian(...) 重构 $H$（L2 投影或 K-exact，§9）。
  2. ref_recon_roundoff_limit 用网格尺度与解抖动抬高最小特征值，避免奇异。

  4. ref_metric_limit_aspect_ratio 限制 AR。
  5. ref_metric_gradation_at_complexity（或 mixed 版本）做梯度限幅 + 复杂度归一（§10）。

9. 梯度与 Hessian 重构

REF_RECON_RECONSTRUCTION 枚举（ref_recon.h:26）有两种：

编号枚举方法
0REF_RECON_L2PROJECTION线性单元基函数的 $L^2$ 投影梯度，再次投影得 Hessian。
1REF_RECON_KEXACTK-精确最小二乘多项式拟合（解析二阶导）。

9.1 L2 投影梯度

在线性 $P_1$ 元下，梯度在每单元为常数。ref_recon_l2_projection_grad （ref_recon.c:38）按下式做体积加权：

$$ \nabla u\Big|_{v_i} = \frac{\sum_{T\ni v_i} V_T\,\nabla u\big|_T}{\sum_{T\ni v_i}V_T} $$

其中 $V_T$ 为单元体积。Hessian 由对梯度的二次投影合成（取对称化）：

H_xx = ∂_x(∂_x u),    H_xy = ½(∂_x∂_y + ∂_y∂_x), ...

实现位于 ref_recon_l2_projection_hessian（ref_recon.c:375-413）。

9.2 K-Exact 最小二乘

对每节点构造一定层数的“stencil cloud”（ref_cloud.c）；用二次多项式

$$ u(\mathbf{x})\approx u_0 + \mathbf{g}^\top\Delta + \tfrac12\Delta^\top H\Delta, \quad \Delta=\mathbf{x}-\mathbf{x}_0 $$

对邻域 $m\ge 9$ 个点求超定最小二乘系统 $A\mathbf{c}=\mathbf{b}$， 其中 $\mathbf{c}=(u_0,\mathbf{g},H)$。ref_recon_kexact_with_aux （ref_recon.c:425）使用 ref_matrix_qr 的 QR 分解求解， 若初次过点不足则向外扩层（最多重试若干次后将该节点 Hessian 置零）。 K-Exact 对各向异性场更稳健。

10. 度量梯度限幅 (Gradation)

无控制时多尺度 Hessian 在解陡变区会让度量沿空间剧烈跳变，导致网格不可用。 Gradation 将相邻节点度量耦合，使度量沿任意路径的对数变化率 受限，从而生成平滑过渡的网格。

10.1 度量空间梯度（Alauzet 公式）

对边 $(P_0,P_1)$ 与方向 $\mathbf{e}=P_1-P_0$，先以 $\mathcal{M}_1$ 算度量距离 $\ell = \sqrt{\mathbf{e}^\top\mathcal{M}_1\mathbf{e}}$， 再用扩张因子

$$ \eta = (1+\ell\,\log r)^{-2}, \qquad r>1\ \text{为允许的相邻边长比上限}, $$

得到 限幅度量 $\widetilde{\mathcal{M}}_1=\eta\,\mathcal{M}_1$。 然后对 $\mathcal{M}_0$ 与 $\widetilde{\mathcal{M}}_1$ 做同时对角化相交 （§11）替换 $\mathcal{M}_0$。两端节点对称处理，迭代到收敛。

实现：ref_metric_metric_space_gradation（ref_metric.c:727）， 注释明确引用 Alauzet, FEAD 2010, eq. (9)。

10.2 混合空间梯度（Mixed-space）

纯度量空间梯度对各向异性度量在等向区会“过紧”。Alauzet §6.2.1 提出 physical-space 与 metric-space 加权混合： 对 $\mathcal{M}_1=R\Lambda R^\top$ 的每特征值方向 $i$，

$$ \eta_i = \Bigl[\;\bigl(1+\sqrt{\lambda_i}\,d\,\log r\bigr)^t\; \bigl(1+\ell\,\log r\bigr)^{1-t}\Bigr]^{-2},\qquad \lambda_i\leftarrow\eta_i\lambda_i, $$

其中 $d=\|\mathbf{e}\|_2$ 为物理欧氏距离，$\ell$ 为度量距离， $t\in[0,1]$ 为混合权（默认 t=1/8，源码 826-828 行；若用户传入越界值则 使用默认）。$r$ 默认 1.5。重构后再做相交。 实现：ref_metric_mixed_space_gradation（ref_metric.c:812）。

实务建议：--gradation 1.5 为度量空间； --gradation -1（负值）触发混合空间，对附面层混合元素更友好。 混合空间在贴体方向许可更陡的度量变化，避免在棱柱层不必要地放大法向间距。

10.3 在指定 complexity 下迭代

ref_metric_gradation_at_complexity（ref_metric.c:1067） 反复执行：① 复杂度归一到目标 $\mathcal{C}^*$；② 一次梯度限幅；③ 重新归一…… 直到复杂度收敛（梯度限幅会改变积分体积）。Mixed 版本同理。

11. 度量相交 (Riemannian Intersection)

给定两个对称正定矩阵 $\mathcal{M}_a,\mathcal{M}_b$，其交 $\mathcal{M}_{a\cap b}$ 应该是 同时满足两者“最严格”要求的最小度量，几何上对应两个椭圆/椭球的相交。 refine 采用同时对角化方法（ref_matrix_intersect）：

  1. 解广义特征值问题 $\mathcal{M}_a^{-1}\mathcal{M}_b\,\mathbf{n}_i=\mu_i\mathbf{n}_i$， 得到非正交基 $N=[\mathbf{n}_1\,\mathbf{n}_2\,\mathbf{n}_3]$。
  2. 对每方向取 $\lambda_i^{a\cap b} = \max\bigl(\mathbf{n}_i^\top\mathcal{M}_a\mathbf{n}_i, \mathbf{n}_i^\top\mathcal{M}_b\mathbf{n}_i\bigr)$ （取较大特征值意味着较短的目标边长）。
  3. $\mathcal{M}_{a\cap b}=N^{-\top}\,\mathrm{diag}(\lambda_i^{a\cap b})\,N^{-1}$。

SMR (ref_metric_smr，ref_metric.c:1798) 是相交的“柔化”版本： 不取 max，而是把 $h^{(b)}$ 夹紧到 $h^{(a)}$ 的 ¼–4 倍范围内 （防止因第二度量过强而剧烈变化），常用于循环 (loop) 中度量的滑动平均。

12. 曲率特征度量 (Curvature Feature Metric)

当未提供 --metric 时，adapt 与 bootstrap 用 ref_metric_from_curvature（ref_metric.c:1317）由 CAD 曲率 派生表面 + 法向各向异性度量。算法：

  1. 取整体包围盒对角线 $D$（ref_egads_diagonal），最大切向间距 $h_{\max}=D/N_{\text{seg/diag}}$。
  2. 对每个表面 face 上的 geom 节点取主曲率 $(\kappa_r,\kappa_s)$ 与对应主方向 $(\mathbf{r},\mathbf{s})$（ref_egads_face_curvature）。
  3. 由“每弧度多少段” $\Delta\theta$ 限制 $r$=半径，得切向间距 $h_r = \Delta\theta/\kappa_r$，$h_s = \Delta\theta/\kappa_s$， 并由 $r_{\text{limit}}=h_{\max}/\Delta\theta$ 上限。
  4. 限制各向异性比 $\mathrm{AR}\le 20$（aspect_ratio=20，第 1345 行）， 用 $\kappa_r\leftarrow\max(\kappa_r,\kappa_s/\mathrm{AR})$ 互相约束。
  5. 法向间距 $h_n = \min(\text{face initial cell}, 2h_r, 2h_s)$（norm_ratio=2）。
  6. 组装局部对角度量 $\mathcal{M}=R\,\mathrm{diag}(1/h_r^2,1/h_s^2,1/h_n^2)\,R^\top$ 并相交到现有度量；相交使得几何特征 + 用户度量同时被尊重。
  7. 体内节点用各向同性 $1/h_{\max}^2 I$ 兜底；表面 crease (法向夹角) 处可触发额外 ramp。

ref_metric_constrain_curvature（ref_metric.c:1289） 在 multiscale 后再用曲率度量做相交，确保 CAD 拐角不被解度量湮没。

  • ref_smooth_tri_ideal(274) / ref_smooth_tri_weighted_ideal(533) — 表面三角的“理想点”：以邻接边的度量加权重心。

  • ref_smooth_tri_quality_around(160) — 邻接最小质量。

18. Cavity 重构 (ref_cavity)

REF_CAVITY（src/ref_cavity.c）封装插入/删除节点的局部 重新四面体化。任何 split / collapse / swap 在内部都构造 cavity 边界面集合， 重新生成 tet 集合，并比较新旧质量。Cavity 也是 cavity-based 自适应 的统一入口（实验：可一次替换数百个 tet）。关键阶段：

  1. 种子单元/节点 → 广度优先扩张 cavity。
  2. 计算 cavity 边界面 (boundary triangles)。
  3. 对每个 boundary triangle + 中心节点形成 tet。
  4. 检查体积正、最小质量 ≥ 门槛。
  5. 原子提交或回滚。

对 CAD 节点会强制几何投影；对 ghost / parallel 节点拒绝跨分区 cavity（避免分布式锁问题）。

19. 混合网格自适应总览（重点章节）

背景：典型粘性 CFD 网格使用结构化棱柱/六面体附面层+ 非结构四面体外场，称为“混合网格 (mixed grid)”。refine 的核心自适应面向 单纯形（tet/tri），但提供两类机制处理混合元素： (1) ref_subdiv 模板化各向异性就地细分（保留 prism/pyr/hex）， (2) ref_shard 就地碎裂为 tet/tri 后走单纯形路径。 此外 ref_layer 与 ref_inflate 提供层装配/膨胀工具， 以及 ref_metric_*_mixed 与混合空间梯度限幅在度量层面尊重各向异性附面层。

┌─────────────────────────────┐ 读入混合网格 ───► │ REF_GRID (tet|pri|pyr|hex) │ └──────────────┬──────────────┘ │ ┌───────────────────────────┼───────────────────────────┐ │ │ │ ▼ ▼ ▼ ref_subdiv ref_shard ref_metric_lp_mixed (各向异性细分, (一致碎裂 + mixed-space 保 prism/pyr) ─►单纯形) gradation │ ▼ standard ref_adapt

19.2 与梯度限幅的关系

混合空间梯度限幅（§10.2）专为混合网格设计： 附面层节点的度量在贴体方向 $\mathbf{n}$ 上特征值非常大（小 $h_n$），切向小。 单纯使用度量空间扩张系数 $(1+\ell\log r)^{-2}$ 会按 $\ell\propto\sqrt{\lambda_n}$ 快速放大法向间距，破坏附面层；混合空间公式按物理距离 $d$ 与 $\sqrt{\lambda_i}\,d$ 分别处理三个特征方向，仅在物理上较远时才放松， 保留贴壁高纵横比。

  • promote_2_all() — 棱柱中若顶/底配对（如 0&5、1&4、2&1）出现 2 mark， 则提升为全 6 条 → 棱柱被 4 等分。
  • ref_subdiv_mark_relax(372) 在 MPI 下用 ref_edge_ghost_int 同步邻 rank 边的 mark，循环直到不再变化。
  • ref_subdiv_unmark_relax(550)、ref_subdiv_unmark_neg_tet_relax(808) —— 反向：若产生负体积或几何不兼容，去掉 mark； unmark_geom_support(857) 在 !allow_geometry 时清掉所有 CAD 支持边的 mark。
  • ref_subdiv_test_impossible_marks(2426) 在分裂前最终校验。

20.7 数学解释

若把 prism 视作 tri 拉伸 $h_n$ 高度， 其 implied metric 张量在 $(\mathbf{r},\mathbf{s},\mathbf{n})$ 框架下为 $\mathrm{diag}(1/h_r^2,1/h_s^2,1/h_n^2)$。 当解的 Hessian 在贴壁切向变化（如激波贴壁），mark_prism_by_metric 检测三角面边的度量比 $\ell_\mathcal{M}$，仅当 > $\sqrt{2}$ （即超出“理想-1”因子根号 2）才标记切向边；侧边由 promote_2_all 维持配对， 保证两端三角面边集合一致，分裂后每个棱柱仍是棱柱，附面层结构保留。

反之 mark_prism_sides 强制法向加密，常配合外部驱动的 $y^+\to 1$ 调节。Mixed-space gradation 的物理距离项 $d$ 在棱柱层为 $h_n\ll 1$， 因此即使度量距离 $\ell$ 大，扩张系数受 $d$ 抑制，相邻棱柱列法向间距保持渐变光滑。

21. ref_shard 一致碎裂

当下游求解器只能吃单纯形（或要 facelift / surrogate 表面），混合元素需要 被无歧义、邻面一致地碎裂为 tet/tri。 ref_shard（src/ref_shard.c）实现“2-对角” vs “3-对角” hex/pri/pyr quad-面碎裂的全局一致选择。

21.1 quad 面对角的两种选择

每个四边形面有 4 个角 0,1,2,3：

3 ------ 2 3 ------ 2 | /| |\ | | / | 或 | \ | | / | | \ | | / | | \ | | / | | \ | 0 ------ 1 0 ------ 1 "mark = 2" "mark = 3" 对角线 0-2 / 等价 对角线 1-3 / 等价 2-对角 3-对角

ref_shard_mark_to_split(node0,node1)(63) 把面 mark 设为 2 或 3， 按 node0/node1 是否命中 face 的 2 或 3 号节点判断。任何冲突（要 2 又要 3）抛 REF_FAILURE。

21.2 一致性松弛 ref_shard_mark_relax(226)

每个 hex 上 6 个 quad 面，对相对的两面（顶/底、左/右、前/后）的对角必须 匹配，否则同一 hex 在两个 quad 面上无法共享一致的 tet 划分。 ref_shard_pair(210) 校验对面的对角线是否同时被 mark： 若不一致则自动追加 mark（“pair-up”），while-loop 直到全局收敛 （多 rank 通过ghost 同步，见 ref_face_ghost）。

具体配对（基于 hex 节点编号 0–7）：

面对对应对角
顶/底面(1-4) ↔ (2-7), (5-0) ↔ (6-3)
前/后面(1-6) ↔ (0-7), (5-2) ↔ (4-3)
左/右面(0-2) ↔ (4-6), (1-3) ↔ (5-7)

21.3 拆分 ref_shard_split(266)

遍历 hex/pri/pyr 与 quad/tri，按 mark 模板调用：

  • ref_shard_add_pri_as_tet(475) — prism → 3 个 tet （根据 3 个侧面 quad 的对角组合，6 种合法情形）。
  • ref_shard_add_pyr_as_tet(602) — pyramid → 2 个 tet （quad 底的对角选择决定）。
  • ref_shard_add_hex_as_tet(662) — hex → 5 或 6 个 tet （“Delaunay-like” 划分，依赖三对面的对角组合）。
  • ref_shard_add_qua_as_tri(1063) — quad → 2 个 tri。

所有新 tet 由 ref_shard_cell_add_local(442) 写入；原 mixed 元素被移除。

21.4 高级 API

  • ref_shard_in_place(ref_grid)(1182) —— 主入口， 对整个 REF_GRID 执行碎裂。translate --shard 即调用本函数。
  • ref_shard_prism_into_tet(915) —— 仅碎棱柱（保留 hex/pyr）。
  • ref_shard_extract_tri(1105)/extract_tet(1146) —— 把碎分结果作为新 grid 提取。
  • ref_shard_verify_faces(1123) —— 校验：碎分后表面/体共享面仍闭合。
  • ref_shard_mark_cell_edge_split(164) —— 由边 cell-edge id 反推哪些 面对角应 mark（用于把 “沿某 hex 边各向异性 split” 的请求转译为面 mark）。

21.5 数学/几何说明

每个 hex 6 面共有 $2^6=64$ 种对角组合，但只有满足三对面 pair-up条件 的组合（4 对 = 16 种）能被一致碎分为 tet。ref_shard_pair 求解的是 线性约束下的 SAT 问题；通过单元局部贪心 + ghost 同步（每 rank 信息一致） 保证全局收敛。该算法相当于在 hex 对偶图上找一个一致的方向场。

26. 场插值 (ref_interp)

REF_INTERP 实现“donor → receptor”空间插值：

  1. 构建 donor 网格的 REF_OCT 八叉树（src/ref_oct.c）。
  2. 对每 receptor 节点 x，oct 查询找出可能 host 单元集合。
  3. 对 tet 计算重心坐标 $(\xi_0,\xi_1,\xi_2,\xi_3)$；若全 ≥ −eps 则 host。
  4. $u_{\text{rec}}=\sum \xi_i u_i$（线性插值；高阶元素用 ref_cell_shape）。
  5. 边界点未命中时退化为最近表面三角投影。
  6. 并行：跨分区 receptor 通过 ref_agents 转发到正确 host rank。
